Any text on the site tagged with a matching key updates here. Edit the value and save.

How this works

  1. Beats — add, edit or remove any beat in the store. Set the title, BPM, key, tags, cover image and the GoDaddy Pay Link for each license. Changes go live instantly, no code.
  2. Cover images — paste an image URL, or upload one if you created a public covers storage bucket in Supabase.
  3. Site Text — edit headlines and copy that are tagged on the pages. Add a new block with the exact key that a page uses.
  4. Pay Links — create a GoDaddy Pay Link per license, then paste it into the beat. Empty links fall back to an email enquiry.

First-time setup: run supabase-schema.sql in Supabase, then mark yourself admin (see the note at the bottom of that file).
